# Generic Pack

The Generic Pack is a small starting point for work that is neither software nor a
document. You name the deliverable when the project starts, and the Quality Contract
declares which commands, structured inspections, or human checks count as evidence.

The pack keeps the same lifecycle and independent review rules as every other pack. It
requires at least one human check so that a deliverable is never accepted on a model's
word alone.

The pack contains no executable logic and cannot widen permissions or weaken repository
rules.
